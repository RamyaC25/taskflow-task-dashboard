
# TaskFlow – Interactive Task Management Dashboard

## Project Overview
TaskFlow is a full-stack task management application that allows users to create, view, update, and delete tasks through a simple and interactive dashboard.

## Objectives
- Build an interactive task management dashboard.
- Connect a frontend to a backend API.
- Perform CRUD operations.
- Store task information in a local database.
- Use asynchronous JavaScript requests.

## Technologies Used
- HTML5 – Frontend structure
- CSS3 – Styling and responsive design
- JavaScript – Frontend functionality
- Node.js – Backend runtime
- Express.js – Backend API
- SQLite – Local database
- Helmet – Security-related HTTP headers

## Features
1. Add new tasks.
2. View all saved tasks.
3. Edit existing tasks.
4. Delete tasks.
5. Select task status: Pending, In Progress, or Completed.
6. Store tasks in an SQLite database.
7. Retain saved tasks after refreshing the page.

## CRUD Operations
- Create: Adds new tasks to the database.
- Read: Retrieves and displays saved tasks.
- Update: Modifies existing task details.
- Delete: Removes tasks from the database.

## Project Structure
- index.html – Main webpage
- style.css – Dashboard design
- script.js – Frontend JavaScript
- server.js – Express backend and API
- database/tasks.db – SQLite database
- package.json – Project dependencies

## How to Run the Project

1. Install Node.js.
2. Open the project folder in VS Code.
3. Install dependencies:

   npm install

4. Start the backend server:

   node server.js

5. Open the browser and visit:

   http://localhost:3000

## Conclusion
TaskFlow demonstrates the development of a full-stack task management application using frontend technologies, a Node.js backend, REST API operations, and an SQLite database.
